# Project plan

`WIP_Tracker_App_Development_Plan.xlsx` is the living backlog for this project — everything
built so far, plus every idea and feature request, with priority and (draft) role visibility.

Workflow: edit the spreadsheet (add ideas, set priority, adjust roles), hand it back, work gets
implemented against it, then the relevant rows get flipped to `Done` and this copy in the repo
is refreshed so it stays the source of truth rather than drifting from whatever's actually built.

Sheets: **Read Me** (full instructions, priority/status definitions), **Roles** (draft — not
finalized), **Features & Backlog** (the main list), **Summary** (auto-counted rollup).
